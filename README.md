## 考核方式

| 考核项目 | 名义占比 | 说明 |
| --- | ---: | --- |
| 作业 1–3 | 每份 7%，共 21% | 三次作业 |
| 课堂测验 | 4% | 第 2 周开始，计入成绩最好的 14 次；无补做或延期 |
| 实验练习 | 4% | 需到实验课完成，计入成绩最好的 8 次；无补做或延期 |
| 期中考试 | 23% | 见上方关键日期 |
| 期末考试 | 55% | 时间以官方考试安排为准 |

作业、课堂测验和实验练习的名义占比合计为 29%，但对总评的贡献最高为 **22%**。因此总评计算为：

```text
FG = min(7A₁ + 7A₂ + 7A₃ + 4Q + 4L, 22) + 23M + 55E
```

其中 `A₁`–`A₃`、`Q`、`L`、`M`、`E` 均为对应项目的得分比例，取值范围为 0–1。例如，期中考试得分 89% 时，`M = 0.89`。

课程已通过“取最好成绩”和 22% 上限为偶发缺席预留空间，因此课堂测验及实验练习不提供补做或延期。其他考核的延期或特殊考虑请遵循 ANU 的正式申请流程。
